# 🎧 Portfólio – Keven Di Camargo Elpidio

Bem-vindo(a) ao meu portfólio!

Este é meu portfólio pessoal, desenvolvido para apresentar minha trajetória como desenvolvedor Front-end, reunindo informações sobre minha formação, habilidades técnicas, projetos e formas de contato. A interface foi construída com React e Sass, adotando uma identidade visual inspirada no universo lo-fi, presente tanto no tema claro quanto no tema escuro.

🔗[Acesse o portfólio](https://portfolio-kevenshtks.vercel.app)

## 🎯 Objetivo

- Criar um portfólio moderno e responsivo - para apresentação profissional.
- Consolidar conhecimentos em React e TypeScript.
- Desenvolver uma interface com identidade visual própria.
- Disponibilizar meus principais projetos e formas de contato em um único lugar.

## 🚀 Funcionalidades

- Alternância entre tema claro e escuro
- Layout totalmente responsivo
- Navegação entre seções
- Exibição dos projetos desenvolvidos
- Links para GitHub e LinkedIn
- Player de música integrado

## 🎨 Estilo e Temas

O portfólio possui duas versões de tema:

- 🌞 Tema Claro: inspirado em cores suaves, tons pastel e vibes relaxantes.
- 🌙 Tema Escuro: atmosfera noturna lo-fi, com sombras leves e contraste suave.

Ambos os temas seguem:

- Estética lo-fi moderna
- Animações sutis
- Layout limpo e minimalista

## 🧩 Estrutura do Projeto

As principais seções do portfólio incluem:

- Home → apresentação inicial e atalhos para as principais seções.
- Sobre mim → trajetória acadêmica e profissional.
- Habilidades → tecnologias e ferramentas.
- Projetos → principais trabalhos desenvolvidos.
- Contato → formas de contato e redes sociais.
- Player de música → componente lateral inspirado em players para fita cassete.

## 🚀 Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/Kevenshtk/Portfolio.git
   ```

2. Acesse o diretório do projeto:

   ```bash
   cd Portfolio
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação:

   ```bash
   npm run dev
   ```

5. Acesse no navegador:

   ```text
   http://localhost:5173
   ```
